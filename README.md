# 梗百科 · 对话接梗版

你照常和她聊天。AstrBot 准备回复时，插件从你的整句话里识别词条、别名和常见改写，用最近几句对话消除歧义。命中时，只为这次回复补一条简短参考，由当前角色决定怎么接话。比如聊键盘时说「你这键盘保熟吗」，她可以把卖瓜台词接到键盘上；聊的是挑西瓜，同样的问法会按字面处理。

## 安装与配置

在 AstrBot WebUI 的插件管理中上传本版 ZIP。插件名沿用 `astrbot_plugin_memewiki`，以便升级时继续读取已有词库和自建词条。首次使用会获取公共词库快照。普通聊天无需调用命令；管理员可用 `/梗库状态` 查看词库和向量索引状态。

默认开启文字识别。使用向量识别时，在 AstrBot 的服务提供商页面配置支持中文的嵌入模型，把提供商 **ID** 填进插件的 `embedding_provider_id`，保存并重载插件。首次建索引会分批调用该提供商，后续复用缓存，仅计算缺少的向量；更换模型后需要重新建索引。第三方提供商将收到待索引的词条（含自建词条）与需要识别的当轮发言。留空时本功能使用本地文字规则。

向量候选须达到 `semantic_threshold`，且与第二名至少相差 `semantic_margin`，再通过文字和语境检查，才会进入本轮提示。这两个值随模型和使用场景而异。若普通聊天频繁误触，可以提高阈值；`preload` 控制整项接梗功能。

## 自建梗与维护

管理员可以用 `/加梗 词名 | 意思和接法` 记录自己的梗，用 `/删梗 词名` 删除自建条目。自建用法优先于同名公共词条。`/更新词库` 可手动同步，`sync_interval_days` 默认 7 天，设为 0 关闭自动同步。日常接梗不需要将消息发给词库网站。
