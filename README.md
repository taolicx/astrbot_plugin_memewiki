# 梗百科 · AstrBot 插件

本地梗词库 + 自动查梗注入上下文，让机器人认得群里的梗。

群友发一句“牛马是什么梗”，机器人不用再一本正经地科普——
它会先查词库，按词条里的“怎么用”接一句，像本来就会。

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动预查 | 收到消息时自动识别梗词，把词条（用法 / 出处 / 标签）注入 LLM 上下文；查不到就什么都不注入，绝不让模型硬猜 |
| 模型工具 | `search_meme_wiki(query)`：模型主动查梗；查不到返回“没收录”，绝不编造 |
| `/梗 <词>` | 手动查梗，例如 `/梗 牛马` |
| `/梗库状态` | 看本地词条数、词库版本、自建词条数、在线兜底开关 |
| `/更新词库`（管理员） | 从 cnmeme.wiki 同步最新词库 |
| `/加梗 词名 \| 用法`（管理员） | 加自建词条，同步时不会被覆盖 |
| `/删梗 <词名>`（管理员） | 删自建词条（删不了内置词库） |
| 每周自动同步 | 默认每 7 天同步一次，可在配置里改间隔或关闭 |

## 安装

要求：AstrBot ≥ 4.5.0。

1. 打开 AstrBot WebUI → **插件市场**（或插件管理 → 安装插件）；
2. 选择“从 GitHub 安装”，填仓库地址：

   ```
   https://github.com/taolicx/astrbot_plugin_memewiki
   ```

3. 安装完成后重启 / 启用插件。

首次启动时，插件会自动从 dsh-memewiki 的公开地址下载词库快照
（约 17 MB，6,792 条，版本 2026-11-05）。如果下载失败，插件仍会
加载，只是本地词库为空——等网络恢复后用 `/更新词库` 同步即可。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `preload` | bool | true | 自动预查：收到消息时自动识别梗并注入上下文 |
| `guide` | bool | true | 注入词条时附带用法指引（先接梗、别科普等） |
| `online` | bool | false | 在线兜底：本地查不到时去 cnmeme.wiki 问一次（只认完全同名） |
| `max_query_chars` | int | 10 | 预查时，一句话不超过多少字才当作词（2–20） |
| `sync_interval_days` | int | 7 | 词库自动同步间隔（天），0 表示不同步 |
| `guidance` | text | （空） | 自定义用法指引，留空用内置文案 |

## 更新机制

热梗更新得快，词库靠三层兜底：

1. **每周自动同步**：插件每 7 天（可配）从 cnmeme.wiki 公开 API
   拉全量清单，只下载新增 / 有更新的词条详情，写库前自动备份
   旧库（`memes.db.bak-<时间戳>`）。站点已删的条目只汇报，本地保留。
2. **在线兜底**（默认关）：本地查不到时，去 cnmeme.wiki 问一次，
   只认与查询词完全同名的条目；同一词 10 分钟内只问一次，
   问到的结果会缓存到本地。预查注入本身不联网——只有本地查不到
   且开了这个开关时才会联网。
3. **手动同步**：管理员发 `/更新词库`，大约 4–5 分钟完成；
   也可以在服务器上跑 `python scripts/sync_cnmeme.py --dry-run`
   先看会改什么（`--no-existing` 只新增不更新）。

自建词条（`/加梗`）存在单独的 `custom_terms.json` 里，同步永远
不会覆盖；在线兜底问到的结果存在 `online_cache.json` 里。

## 已知限制（诚实说明）

- **未在真实 AstrBot + QQ 环境下测试过**。AstrBot 的插件 API
  （Star、on_llm_request、llm_tool、command、配置 schema）是按
  AstrBot v4.30.0-alpha.1（2026-11-15）的官方文档与源码核对过
  的，本地有独立测试覆盖查找、注入、节流与同步逻辑，但真机
  效果以实际部署为准。
- 词库快照是 2026-11-05 的版本（6,792 条），**不是所有梗都有**。
  例如“蚌埠住了”就不在快照里——同步后如果站点收录了就会补上；
  没收录的可以 `/加梗` 自己补，或开在线兜底。
- 在线兜底只认完全同名：近似、缩写变体问不到（本地词库的别名
  匹配不受这个限制）。
- 同步需要联网，全量扫描约 4–5 分钟，期间不影响正常查梗。
